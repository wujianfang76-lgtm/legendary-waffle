# Contributing

Thanks for considering a contribution.

## Good contributions

- Add practical content angles for real beauty creators.
- Improve safe-language guidance.
- Add tests for generator behavior.
- Improve examples and documentation.

## Content safety

Please avoid:

- guaranteed wealth, relationship, or fate claims
- fixed personality judgments based on facial features
- medical or treatment promises
- copy that shames clients

Prefer wording such as:

- "first impression"
- "aesthetic reference"
- "may look more..."
- "consultation should confirm..."
