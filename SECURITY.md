# Security Policy

Beauty Content Kit does not process private customer data by default. It is a
local command-line content generation helper.

## Reporting a vulnerability

Please open a private security advisory on GitHub if the repository is hosted
there, or contact the maintainer directly.

## Content safety

This project treats unsafe content claims as a product risk. Please report
templates or examples that include:

- guaranteed financial, relationship, medical, or fate outcomes
- fixed personality judgments based on facial features
- client-shaming language
- instructions that could mislead clients about beauty results
