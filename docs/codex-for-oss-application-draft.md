## Why this repository is eligible

Beauty Content Kit is a public open-source CLI that helps beauty creators turn
professional consultation knowledge into safer short-video topic angles. It
supports lip, brow, and eye content generation with built-in safe-language notes
to avoid guaranteed outcome claims, client shaming, or fixed personality
judgments. The project is actively maintained with tests, documentation, issue
templates, and CI for public collaboration.

## API credit use

API credits would be used to improve content generation quality, add bilingual
prompt templates, generate script outlines, test safe-language rewrites, and
build maintainer automation for reviewing new content-angle contributions.
