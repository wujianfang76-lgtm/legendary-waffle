# Maintenance Plan

This project is maintained as a practical toolkit for beauty creators and local
beauty studios.

## Near-term maintenance

- Add more real-world content examples for lip, brow, and eye topics.
- Expand safe-language checks for claims about fate, wealth, relationships, and
  medical-style results.
- Improve script outlines with platform-specific formats.
- Add CSV export for planning weekly short-video calendars.
- Publish a first tagged release after the CLI stabilizes.

## Review checklist

New content examples should:

- be useful for real creator workflows
- avoid guaranteed outcomes
- avoid fixed personality judgments
- include a concrete client concern or consultation angle
- include a practical call to action
